# Фронтенд «Кладочные материалы» — лабораторная 5

Базовое SPA для гостя на React + TypeScript (Vite) и React-Bootstrap.
Тема: расчёт расхода строительных материалов для кладки стен. Услуги — типы кладочных материалов
(кирпич, блоки) с раствором на 1 м³ кладки и расходом в шт./м³.

Данные карточек берутся из mock-коллекции (`src/modules/masonry-material-mock.ts`), бэкенд не нужен.

## Запуск

```bash
npm install
npm run dev
```

Приложение: http://localhost:5173/masonry-materials (порт 3000 занят бэкендом).

## Страницы

### Плитка — `/masonry-materials`

Список опубликованных кладочных материалов с фильтром по расходу.

| Элемент | Описание |
|---|---|
| Заголовок «Фильтрация: расход (в шт./м³) до» | — |
| Ползунок | максимальный расход, от 0 до 400 шт./м³; рядом выводится текущее значение |
| Кнопка «Найти» | применяет фильтр: показываются материалы с расходом не больше значения ползунка; во время загрузки кнопка заблокирована и показывает индикатор |
| Карточка материала | изображение (или изображение по умолчанию), название, расход в шт./м³, количество лайков ❤ |
| Карточка — ссылка | переход на страницу «Лента» с этим материалом (`/masonry-materials/feed?id=2`) |

### Лента — `/masonry-materials/feed`

Один кладочный материал на весь экран. Материал выбирается параметрами адреса:

| Адрес | Материал |
|---|---|
| `/masonry-materials/feed?next=true` | первый |
| `/masonry-materials/feed?id=2` | с этим id |
| `/masonry-materials/feed?id=2&next=true` | следующий после id по кругу |
| `/masonry-materials/feed` | без параметров не показывается («Услуга не найдена») |

| Элемент | Описание |
|---|---|
| Видео на фоне | видео материала (или видео по умолчанию) |
| Раствор | раствор на 1 м³ кладки, м³/м³ |
| Расход | расход, шт./м³ |
| Иконка ❤ с числом | количество лайков (гостю только просмотр) |
| Кнопка «›» (Следующий) | переход к следующему материалу по кругу (`?id=…&next=true`) |
| Название и описание | описание свёрнуто до 2 строк |
| Кнопка «больше» / «меньше» | разворачивает и сворачивает описание |

### Нижняя панель (на всех страницах)

| Пункт | Гостю |
|---|---|
| Лента | доступен — переход на `/masonry-materials/feed?next=true` |
| Добавление | недоступен (`/masonry-materials/draft`) |
| Плитка | доступен — переход на `/masonry-materials` |
| Вход | недоступен (`/users/login`) |

## Изображение и видео по умолчанию

Файлы лежат в `public/`:
`masonry-material-default-image.png` и `masonry-material-default-video.mp4`.
Они показываются, если поле `imageUrl` / `videoUrl` у материала пустое.
В mock у всех материалов `imageUrl` и `videoUrl` равны `null`, поэтому везде показываются файлы по умолчанию.

## Структура

```
src/
  main.tsx                                  точка входа, подключение стилей Bootstrap
  App.tsx                                   маршруты
  MasonryMaterialLayout.tsx                 «экран» и нижняя панель
  masonry-material-routes.ts                адреса страниц
  masonry-material-style.css                стили
  components/
    MasonryMaterialTabBar.tsx               нижняя панель (Nav)
    MasonryMaterialCard.tsx                 карточка материала (Card)
    MasonryMaterialConsumptionFilter.tsx    фильтр по расходу (Form.Range, Button)
  pages/
    MasonryMaterialTilesPage.tsx            страница «Плитка»
    MasonryMaterialFeedPage.tsx             страница «Лента»
  modules/
    masonry-material-types.ts               тип услуги
    masonry-material-mock.ts                mock-коллекция
    masonry-material-api.ts                 получение списка и ленты (из mock)
    masonry-material-defaults.ts            пути к файлам по умолчанию
```

## Используемые хуки

- `useState` — список материалов, значение ползунка, загрузка, материал ленты, развёрнутое описание;
- `useEffect` — загрузка списка при открытии «Плитки» и загрузка материала при смене `id` в «Ленте»;
- `useSearchParams` — параметры `id` и `next` из адреса ленты;
- `useNavigate` — переходы по кнопке «Следующий» и пунктам панели (карточка — ссылка `Link`);
- `useLocation` — подсветка активного пункта панели.
