# Страницы приложения «Кладочные материалы»

## Лента — `/masonry-materials/feed`

Один тип кладочного материала на весь экран. Доступна гостю.

| Элемент | Описание |
|---|---|
| Видео на фоне | видео типа кладочного материала (или видео по умолчанию) |
| Раствор | раствор на 1 м³ кладки, м³/м³ |
| Расход | расход, шт./м³ |
| Иконка ❤ с числом | количество лайков; авторизованный пользователь ставит и снимает лайк нажатием |
| Кнопка «›» (Следующий) | переход к следующему типу кладочного материала по кругу |
| Название | название типа кладочного материала |
| Описание | краткое описание, свёрнуто до 2 строк |
| Кнопка «больше» / «меньше» | разворачивает и сворачивает описание |

## Добавление — `/masonry-materials/draft`

Страница «Черновик» для добавления типа кладочного материала в два шага. Доступна только авторизованному пользователю.

Шаг 1 — создание черновика:

| Элемент | Описание |
|---|---|
| Поле «Название» | название типа кладочного материала |
| Поле «Изображение» | файл изображения; до выбора файла показывается изображение по умолчанию |
| Поле «Видео» | файл видео; до выбора файла показывается видео по умолчанию |
| Кнопка «Далее» | создаёт черновик с названием, изображением и видео и открывает шаг 2 |

Шаг 2 — публикация черновика:

| Элемент | Описание |
|---|---|
| Поле «Название» | название черновика, только для чтения |
| Поле «Краткое описание» | описание типа кладочного материала |
| Поле «Раствор, м³/м³» | раствор на 1 м³ кладки |
| Поле «Расход, шт./м³» | расход на 1 м³ кладки |
| Кнопка «Опубликовать» | публикует черновик и открывает страницу «Плитка» |

## Плитка — `/masonry-materials`

Список опубликованных типов кладочных материалов с фильтром по расходу. Доступна гостю.

| Элемент | Описание |
|---|---|
| Заголовок «Фильтрация: расход (в шт./м³) до» | — |
| Ползунок | максимальный расход, от 0 до 400 шт./м³; рядом выводится текущее значение |
| Кнопка «Найти» | применяет фильтр: показываются типы с расходом не больше значения ползунка |
| Карточка | изображение (или изображение по умолчанию), название, расход в шт./м³, количество лайков ❤ |
| Нажатие на карточку | переход на страницу «Лента» с этим типом кладочного материала |
| Кнопка удаления | показывается авторизованному пользователю на карточках его типов кладочных материалов, удаляет тип |

## Вход — `/users/login`

Форма аутентификации. После входа пункт меню «Вход» заменяется на «Выход».

| Элемент | Описание |
|---|---|
| Поле «Логин» | логин пользователя |
| Поле «Пароль» | пароль пользователя |
| Кнопка «Войти» | аутентификация, после входа переход на страницу «Плитка» |
